# 🚀 TaskMan - Smart Task Manager

TaskMan is a modern and user-friendly task management application built with React. It helps users organize daily tasks efficiently using categories, priorities, progress tracking, search functionality, and dark/light mode support.

## ✨ Features

- ✅ Add new tasks
- 🗑️ Delete tasks
- ✏️ Edit tasks
- 🔍 Search tasks instantly
- 📊 Progress tracker
- 🎯 Task priority management (High, Medium, Low)
- 📁 Category-based organization
- 🌙 Dark Mode / ☀️ Light Mode
- 💾 Local Storage support
- 🧹 Clear All Tasks option
- 📱 Responsive design

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- CSS3
- HTML5
- Local Storage API

## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/TaskMan.git
```

2. Navigate to project directory

```bash
cd TaskMan
```

3. Install dependencies

```bash
npm install
```

4. Start development server

```bash
npm run dev
```
